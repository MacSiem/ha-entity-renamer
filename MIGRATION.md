# Entity Renamer — migration information

## Current transition update

The 4.6.2 Dashboard plugin is a transition update. It retains the existing
4.6.1 card and registry rename workflow; it does not install a backend or
remove your card. **No migration action is required now. Do not remove the
existing installation or its dashboard resource.**

Entity Renamer is planned to move to one Home Assistant Integration package
containing the card and backend. A future HACS update may require a one-time
migration. Before performing a future migration, make a full Home Assistant
backup and read the completed guide.

## Future migration

The integration package and the migration path are still being tested. The
exact steps, compatibility and recovery instructions will be added here after
that path is verified and before the integration release. This page does not
instruct you to uninstall, replace resources or modify your configuration now.

# Entity Renamer — informacje o migracji

## Obecna aktualizacja przejściowa

Plugin Dashboard 4.6.2 jest aktualizacją przejściową. Zachowuje kartę i sposób
zmiany nazw z 4.6.1; nie instaluje backendu ani nie usuwa karty. **Nie musisz
teraz wykonywać migracji. Nie usuwaj obecnej instalacji ani jej zasobu
w dashboardzie.**

Entity Renamer ma przejść na jeden pakiet Integration zawierający kartę
oraz backend. Przyszła aktualizacja HACS może wymagać jednorazowej migracji.
Przed przyszłą migracją wykonaj pełną kopię zapasową Home Assistant i przeczytaj
uzupełniony przewodnik.

## Przyszła migracja

Pakiet integracji i ścieżka migracji są nadal testowane. Dokładne kroki,
zgodność oraz instrukcje odzyskiwania zostaną dodane po sprawdzeniu tej ścieżki,
przed wydaniem integracji. Ta strona nie zaleca teraz odinstalowywania,
zastępowania zasobów ani zmiany konfiguracji.
